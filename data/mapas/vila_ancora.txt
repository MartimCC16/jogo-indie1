; MAPA DA VILA ÂNCORA  (40 colunas x 26 linhas, cada letra = 1 tile 16x16)
; Linhas que começam com ";" são comentários (o jogo ignora).

; LEGENDA:
;   .  grama            ,  grama com flor     =  caminho de terra
;   s  areia            -  espuma (beira-mar) ~  água (bloqueia)
;   R  rocha na grama (bloqueia)   r  rocha na areia (bloqueia)
;   F  cerca (bloqueia)
;   T  floresta (bloqueia; árvore grande em tiles alternados)
;   A  árvore grande sozinha (só o tronco bloqueia; dá pra passar atrás)
;   t  arvorezinha de 1 tile (bloqueia)
;   ^  telhado          #  parede             J  janela
;   D  porta            (telhado/parede/janela/porta bloqueiam)
;
; Para mudar o mapa: edite as letras abaixo, salve, abra a cena

; "Gerar mapa a partir do texto" no Inspetor. Depois salve a cena (Ctrl+S).
; =====================================================================
